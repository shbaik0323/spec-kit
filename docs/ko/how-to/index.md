# How to

Spec Kit 실무를 이해하고, 선택하고, 프로젝트 작업에 적용하세요.
이 가이드들은 개발 접근 방식, 프로젝트 컨텍스트, 복잡한 기능, 명세 유지 관리를
다루며, 인증과 Spec Kit 자체의 개발도 포함합니다.

| 한 저장소 안의 여러 프로젝트에서 작업하기 | [모노레포에서 작업하기](monorepo.md) |
| 컴포넌트 간 인터페이스에 합의하기 | [계약을 정의하고 발전시키기](contract-driven-development.md) |
| 구현을 관리 가능한 컨텍스트 한도 안에 유지하기 | [복잡한 기능 구현하기](complex-features.md) |
