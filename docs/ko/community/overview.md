# 커뮤니티

Spec Kit 커뮤니티는 Spec Kit으로 할 수 있는 일을 넓혀 주는 통합, 확장, 프리셋, 워크플로, 워크플로 스텝, 번들, 워크스루, 관련 프로젝트를 만듭니다. 모든 커뮤니티 기여는 각 작성자가 독립적으로 만들고 유지 관리합니다.

> [!NOTE]
> 설치하기 전에 커뮤니티 소스 코드를 검토하고 여러분의 판단에 따라 사용하세요.
> 카탈로그 등재는 감사나 보증이 아닙니다.

탐색 전용 커뮤니티 소스와 승인된 비공개 소스가 어떻게 맞물리는지는
[카탈로그 레퍼런스](../overview/catalogs.md)에서 알아보세요.

## 통합

통합은 Spec Kit을 코딩 에이전트에 연결합니다. 커뮤니티 외부 어댑터에는 내장
에이전트와 별개인 자체 패키지 및 카탈로그 계약이 있습니다.

[커뮤니티 통합 둘러보기](integrations.md)

## 확장

확장은 도메인 특화 명령, 외부 도구 연동, 품질 게이트 등 Spec Kit에 새로운 기능을 추가합니다. 70명 이상의 작성자가 만든 130개 이상의 커뮤니티 확장이 접근성 거버넌스부터 다중 에이전트 오케스트레이션까지 모든 것을 다룹니다.

[커뮤니티 확장 둘러보기 →](extensions.md)

## 프리셋

프리셋은 도구를 바꾸지 않고 템플릿, 명령, 용어를 오버라이드해 Spec Kit의 동작 방식을 사용자 정의합니다. 커뮤니티 프리셋은 언어 현지화부터 완전히 다른 개발 방법론까지 다양합니다.

[커뮤니티 프리셋 둘러보기 →](presets.md)

## 워크플로

워크플로는 재사용 가능한 스텝을 작성자가 선택한 입력, 제어 흐름, 리뷰 게이트와
함께 반복 가능하고 재개 가능한 프로세스로 합성합니다.

[커뮤니티 워크플로 둘러보기](workflows.md)

## 워크플로 스텝 타입

워크플로 스텝 타입은 워크플로가 `type:`으로 선택할 수 있는 재사용 가능한 실행
동작을 추가합니다. 커뮤니티 카탈로그는 탐색 전용입니다. 스텝을 설치하거나 실행하기
전에 그 소스를 검증하세요.

[커뮤니티 워크플로 스텝 타입 둘러보기](workflow-steps.md)

## 번들

번들은 확장, 프리셋, 워크플로, 스텝을 함께 설치할 수 있는 역할 또는 팀 스택으로 합성합니다.

[커뮤니티 번들 둘러보기 →](bundles.md)

## 워크스루

다양한 시나리오, 언어, 프레임워크에서 스펙 주도 개발이 실제로 동작하는 모습을 보여 주는 단계별 가이드입니다.

[커뮤니티 워크스루 둘러보기 →](walkthroughs.md)

## 프렌즈

VS Code 확장, Claude Code 플러그인 등 Spec Kit을 확장하거나, 시각화하거나, 그 위에 무언가를 만드는 커뮤니티 프로젝트입니다.

[프렌드 프로젝트 둘러보기 →](friends.md)
