# 워크플로 스텝

워크플로 스텝은 실행 가능한 동작의 재사용 가능한 단위를 제공합니다. 워크플로는
`type:`으로 스텝 타입을 선택하고 그 설정을 제공하며, 워크플로 엔진이 순서 지정,
실행 상태, 체크포인트, 재개를 소유합니다.

## 내장 타입과 사용자 정의 타입

내장 타입은 Spec Kit과 함께 제공됩니다. 명령과 프롬프트를 호출하고, 셸 작업을
실행하고, 리뷰 게이트에서 일시 정지하고, 분기·루프·팬아웃을 표현합니다. `type`을
생략하면 `command`가 선택됩니다. `workflow` 호출은 같은 실행 안에서 설치된 다른
워크플로를 합성합니다.

사용자 정의 스텝 패키지는 Python으로 구현된 타입을 추가합니다. 각 패키지는 타입
키 하나를 제공하며, 그것을 사용하는 워크플로와 별도로 설치됩니다. 재사용 가능한
실행 동작이 기존 타입에 맞지 않을 때 사용자 정의 타입을 사용하고, 기존 스텝을
합성하는 것으로 충분하다면 워크플로를 사용하세요.

## 사용자 정의 스텝을 설치하기 전에

설치하고 사용하기 전에 소스, 의존성, 부수 효과를 검토하세요.
설치는 Python을 임포트하지 않고 패키지를 검증하고 복사합니다.
이후의 `specify workflow add`, `run`, `resume`은 설치된 스텝 패키지를 로드하며,
특정 스텝이 실행 대상으로 선택되기 전에도 임포트 시점 코드를 여러분의 권한으로
실행합니다.

커뮤니티 카탈로그 등재는 탐색 메타데이터이지, 코드 감사나 보증, 설치 허가가
아닙니다. 활성 소스는 `specify workflow step catalog list`로 확인하세요.

## 워크플로에서 스텝 사용하기

사용자 정의 타입을 검토하고 설치한 뒤, 정확한 타입 키를 선택하세요.

```yaml
steps:
  - id: check
    type: my-step
```

추가 설정과 출력은 타입에 따라 다릅니다. 스텝은 워크플로 엔진이 실행하며, 별도의
스텝 실행 명령은 없습니다.
