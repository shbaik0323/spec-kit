# None: 공유 스캐폴딩만

에이전트 중립 프로젝트에는 `none` 통합을 사용하세요. 에이전트별 명령, 스킬, 설정,
훅 없이 공유 `.specify/` 스캐폴딩을 설치합니다. 코딩 에이전트는 필요하지 않습니다.

## 다중 설치 안전성

이 통합은 에이전트별 파일을 생성하지 않으므로 다중 설치 안전으로 선언되어
있습니다. `--force` 없이 공존하려면 설치된 다른 통합도 안전하다고 선언되어 있어야
합니다.
[공통 다중 설치 규칙](cli.md#can-i-install-multiple-integrations-in-the-same-project)을 참고하세요.

## 설정

```bash
specify init my-project --integration none
```

기존 프로젝트에서 현재 기본 통합을 교체하려면 다음과 같이 합니다.

```bash
specify integration switch none
```

`none`이 이미 설치되어 있으면 `switch`는 그것을 기본값으로 선택하기만 하고 다른
통합을 제거하지 않습니다. 설치, 활성화, 정리는
[통합 관리](cli.md)를 참고하세요.

## 공유 파일과 제거

템플릿, 스크립트, 컨스티튜션, 번들된 워크플로, 프로젝트 메타데이터는 `.specify/`
아래에서 계속 사용할 수 있습니다. 이 통합의 생성 파일 매니페스트는 비어 있습니다.
`none`을 제거해도 공유 스캐폴딩이나 소유하지 않은 파일은 제거되지 않습니다.

선택적인 혼합 에이전트 팀 접근 방식은
[팀에서 작업하기](index.md#working-in-a-team)를 참고하세요.

## 워크플로 제한

이 통합은 워크플로 명령 또는 프롬프트 스텝을 디스패치할 수 없습니다. 그 스텝들을
실행하려면 CLI 디스패치를 지원하는 에이전트 통합으로 전환하세요.
통합별 설정 옵션은 없습니다.
